Step 3 — Monitoring, Auditing & Architecture

Owner: Omar

Objective

Monitor AWS infrastructure health, record account activity for auditing, track cloud spending, and document the initial project architecture.

Implementation Summary

- Enabled AWS CloudTrail to record management events for auditing and activity tracking.
- Configured Amazon CloudWatch monitoring to observe AWS resource metrics, logs, and alarms.
- Set up an AWS CloudWatch dashboard to centralize monitoring information.
- Configured AWS Budgets to monitor estimated cloud costs and provide budget notifications.
- Prepared the initial architecture diagram to illustrate the main AWS components and their relationships.
